1980s COLOR · NEON PINK / CYAN / PURPLE
// 元素 02 · 声音

合成器浪潮

电子合成器替代了管弦乐团，成为动作片与青春片的标配声场，听一遍就回到那个年代。

1980s SOUND · SYNTHWAVE / ELECTRO
// 元素 03 · 介质

录像带与录像厅

VHS 把电影院搬进客厅，录像厅则成了整代人的启蒙课堂。介质本身也成了美学符号。

1980s MEDIA · VHS / VIDEO STORE
// 元素 04 · 时尚

大垫肩与宽西裤

夸张的剪裁与高饱和布料，是那个年代自信与张扬最直接的表达。

1980s FASHION · SHOULDER PADS
// 元素 05 · 游戏

像素与街机

街机厅里的一枚硬币、客厅里的 8-bit 主机，构成了最早一批数字原住民的童年。

1980s GAME · ARCADE / 8-BIT
